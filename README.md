# Kettenantrieb-f-r-Dachfenster
Elektrische Kettenantriebe an Dachfenstern automatisieren Lüftung und RWA. Sie bewältigen hohe Lasten wie Schnee (bis 1000 N) und sicheren Winddichtigkeit. Dank Schwenkkonsolen folgen sie der Fensterbewegung materialschonend. Während 230 V der Lüftung dient, ist 24 V Standard für RWA-Sicherheit mit Notstrom.
